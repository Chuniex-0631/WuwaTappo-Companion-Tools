## 覆盖内容

- **共享状态机**：低余额领取后的隐藏、双槽处理、等待响应、稳定观察、超时退避、禁用按钮、不可读状态、点数停滞及恢复；自动补点和纯监控模式均覆盖。
- **界面解析**：禁用按钮与倒计时同时暴露时的状态优先级及枚举顺序；无效坐标过滤；隐藏/倒计时持续交替时仍进入响应超时退避。
- **输入发送**：完整接受、拒绝与部分接受的 F24/鼠标输入；补发抬起和补发失败路径；原生输入结构布局。
- **托盘生命周期**：反复隐藏/恢复、窗口句柄保留、透明动画归一、隐藏时停止、菜单恢复与退出、重复清理、实际应用接收恢复消息及隐藏后关闭。
- **代码审查**：进程绑定、过期任务隔离、点击前重新检查、发送与停止同步、旧版互斥兼容、输入失败提示及统一退出入口。

状态机和解析回归使用离线数据；输入发送替换为测试函数；生命周期回归使用本地测试窗口。没有登录真实账号，没有发送真实键鼠输入，也没有实际领取奖励。

## 桌面实测

Windows 当前 125% 缩放（120 DPI）：已查看两款实际窗体，标题、主按钮和状态区域无明显裁切；已观察工具箱关闭按钮及 AutoPilot 的 Alt+F4 退出测试窗口。预览使用模拟输入接口。

自动生命周期测试覆盖实际窗体隐藏与恢复消息、菜单停止及退出；没有通过真实通知区域图标手动验证全部菜单。发现正在运行的旧版 AutoPilot 时，新版启动已显示先退出旧版的提示。未为了测试停止用户的旧版助手。

两款测试合计 **3187 项断言**。工作线程测试覆盖补点预算、输入租期、失效世代、发送失败与停止后不再发送；Toolkit 还验证输入失败后的界面恢复。

未完成全量 100%、125%、150% DPI、多显示器、系统关机和 Explorer 重启组合测试时，不将这些项目记为已验证。

## 边界与恢复方式

- 测试覆盖列出的状态和输入边界，不代表所有设备、桌宠版本或 Windows 环境都不存在问题。
- 界面解析依赖 Wuwa Tappo 的可访问性布局。桌宠升级后可能需要适配；无法可靠读取时暂停自动操作。
- UIA 提供方永久挂起并占满两个读取名额时，输入保持暂停，可退出并重开助手恢复。程序不会终止或修改桌宠进程。
- 托盘通知可能被 Windows 关闭，图标也可能被收纳；可展开通知区域或再次启动新版 EXE 恢复窗口。
- 未使用真实账号验证奖励到账。客户端界面变化仅用于重新规划，实际奖励以桌宠背包和账号侧记录为准。
