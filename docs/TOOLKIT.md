# 桌宠工具箱 1.4.0：手动控制与宝箱监控

Toolkit 提供两个独立入口：手动计数加速和宝箱监控。它与 AutoPilot 共用槽位识别、领取等待及逐槽重试逻辑，但由用户决定何时补点。
两款工程均引用 `src/Shared/` 的同一份实现，Toolkit 使用关闭自动补点的监控模式。

## 操作方式

- 点击“开始运行”，以约 50 次/秒发送 F24；Pause 可开始或停止计数加速。
- 点击“开始监控”，读取上、下槽位并自动尝试领取可点击宝箱。
- 监控启动时停止计数加速；监控运行期间不会启动连点。
- 停止监控后不会自动恢复连点，需要时手动开启。
- 最小化后继续运行；停止或关闭时释放内部按键和后台任务。

## 低点数时的显示

原桌宠在余额不足 1000 时隐藏两槽，1000～1999 时只显示一槽，至少 2000 时两槽才均具备展示条件。
因此“空/隐藏”只表示没有读到该位置的可见控件，不代表底层没有宝箱或冷却。

例如领取前余额 1500，领取扣点后余额 500，原来的宝箱按钮和两个倒计时都可能正常隐藏。
Toolkit 会结束当前操作等待、回到监控，不会因为看不到原槽倒计时就反复点击旧位置。

## 监控中的状态闭环

| 当前观察 | 工具箱动作 |
| --- | --- |
| 点数或窗口暂不可读取 | 暂停领取，恢复后继续 |
| 点数不足 1000、槽位隐藏 | 等待用户补点，不启动内部连点 |
| 可点击宝箱出现 | 复核槽位和位置，鼠标空闲后点击一次 |
| 操作后原槽变成隐藏或倒计时 | 连续观察状态变化后回到监控 |
| 原宝箱持续存在或没有响应 | 按该槽位退避，稍后重试 |
| 另一槽可领取 | 在当前事务结束后处理另一槽 |
| 宝箱按钮禁用或处理动画中 | 等待桌宠完成处理 |

需要补点时，可以通过正常键鼠操作积累点数，或停止监控后手动开启计数加速。
若希望补点、等待和领取全部自动安排，请使用 AutoPilot。

## 结果与权限

本版不统计开箱次数，也不把客户端预测倒计时当作奖励到账证明。奖励以桌宠背包和账号侧结果为准。

识别使用 Windows UI Automation，无需 OCR 或截图模板。工具不发网络请求；桌宠本体的登录与领取仍使用其自身网络流程。
管理员权限用于匹配桌宠输入窗口的权限级别，每次启动申请一次。
